## 2024-06-25 - Avoid O(N²) String Concatenation in Loops
**Learning:** Using `strcat` and `strlen` to append strings repeatedly within a loop creates an O(N²) performance bottleneck, as they traverse the entire string on each iteration. In addition, when dynamically growing buffers inside loops with `xrealloc`, an `if` statement to double the capacity can be insufficient if the appended string is very large; this must be handled with a `while` loop.
**Action:** Always maintain a `curr_len` variable to track string length manually when building large strings inside loops. Use `memcpy(buffer + curr_len, ...)` instead of `strcat` to achieve O(1) appends, and use a `while` loop (`while (curr_len + append_len >= cap) { cap *= 2; }`) to guarantee enough capacity when reallocating.
