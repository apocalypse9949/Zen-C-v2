## 2024-05-19 - Replace loop strcat with memcpy in C codebase
**Learning:** Using `strcat` or `strlen` repeatedly inside loops for building large comma-separated strings (like function template parameters or generic arguments) results in an unexpected O(N^2) bottleneck, known as Schlemiel the Painter's algorithm. Also discovered that static bounds sizes (like `MAX_ERROR_MSG_LEN`) were prone to buffer overflow when built with unchecked `strcat`.
**Action:** When performing heavy string concatenation loops in C, manually track lengths (e.g., `curr_len`) and append using `memcpy()`. Ensure appropriate size doubling (`while (curr_len + n > cap) { cap *= 2; }`) when allocating dynamically, or explicitly bounds-check (`if (curr_len + n < MAX)`) for statically sized buffers to preserve O(N) performance and eliminate vulnerabilities.
