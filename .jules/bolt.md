## 2026-05-07 - O(N^2) String Building in `extract_call_args`
**Learning:** `extract_call_args` in `src/codegen/codegen_utils.c` was traversing the entire built string repeatedly using `strlen` and `strcat` in a loop over function arguments, causing O(N^2) time complexity. Furthermore, the allocation size `strlen(args) + 1` was a latent buffer overflow risk since extracting variable names and appending commas/spaces could produce a string longer than the original input (e.g. `"a,b"` -> `"a, b"`).
**Action:** Always manually track the length of the built string (`curr_len`) and use `memcpy` for concatenation instead of `strcat`/`strlen` in loops. For buffers built by inserting separator characters, allocate enough space (`len * 2 + 1`) to account for the maximum possible expansions.
