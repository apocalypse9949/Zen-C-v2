## 2024-05-18 - Fix Command Injection Vulnerability in Comptime Execution
**Vulnerability:** The `run_comptime_block` function in `src/parser/parser_stmt.c` used the insecure `system()` function to compile and run comptime code. This introduced a significant command injection risk, as arguments passed directly to the shell could contain malicious metacharacters. It also utilized `rand()` in the current working directory for temporary file creation, increasing predictability and exposing race conditions.
**Learning:** `system()` evaluates strings via the system shell (e.g. `/bin/sh -c` or `cmd.exe /c`), exposing the application to shell injection. Generating temporary files securely requires combining system-level temporary directories (`z_get_temp_dir()`) with unpredictable/unique runtime information like process IDs (`z_get_pid()`).
**Prevention:** Avoid `system()` for executing shell commands. Construct commands safely utilizing structured argument arrays, like the `ArgList` utility provided in `src/utils/cmd.h`, and execute them using `arg_run()` or `z_run_command_capture()`. Employ robust temporary file creation strategies utilizing `mkstemp` or combinations of PID/counters in isolated temp directories.
