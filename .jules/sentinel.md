## 2026-05-13 - [Command Injection and Symlink Vulnerability in Comptime Block Execution]
**Vulnerability:** `system(cmdbuf)` was used with unescaped arguments generated from `sprintf` in `src/parser/parser_stmt.c`, leading to Command Injection. Temporary files were generated using `rand()` and `fopen(..., "w")` in `/tmp`, leading to a symlink race condition (CWE-377).
**Learning:** Security fixes involving `execvp` or custom wrappers (`z_run_command_capture`) must consider argument formatting. `z_get_run_prefix()` requires different handling depending on its return value (`"./"` requires path concatenation using `arg_list_add_fmt`, while wrappers like `"wine "` need array splitting). Additionally, variables of type `size_t` must not be compared to `0` or negative values for error handling in functions like `read()`; `ssize_t` must be used to track the last operation.
**Prevention:** Avoid `system()` for executing dynamic commands; always use array-based execution parameters like `ArgList`. For temporary file creation in shared directories, use `mkstemp()` or `mkstemps()` and access the returned file descriptor using `fdopen()`. When parsing `read()` outputs, verify loop logic properly increments via `ssize_t`.
